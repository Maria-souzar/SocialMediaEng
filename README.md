# Sobre
O presente projeto consiste no desenvolvimento de um website voltado à prestação de serviços na área de Social Media, com o objetivo de apresentar informações sobre o trabalho desse profissional e oferecer uma experiência interativa ao usuário.

A aplicação contempla as seguintes funcionalidades e páginas:

>Tela Inicial: apresentação dos serviços e breve introdução ao tema.

>Página Sobre: detalhamento das atividades e competências do profissional de Social Media.

>Cadastro e Login: sistema de autenticação para clientes, permitindo criação e acesso a contas pessoais.

>Carrinho de Serviços: funcionalidade para seleção e armazenamento de serviços de interesse, com persistência de dados utilizando LocalStorage.

O desenvolvimento será realizado com React, Vite e TypeScript, garantindo alta performance, tipagem estática e maior segurança no código. A arquitetura prioriza modularidade, escalabilidade e manutenção simplificada, assegurando que o produto final seja tecnicamente consistente e visualmente atrativo.
